## 📖 О проекте
Учебный проект, представляющий собой веб-приложение для публикации и просмотра фотографий. В проекте реализована работа с DOM, обработка пользовательских событий, загрузка изображений, фильтрация и работа с формами на чистом JavaScript.

## 🛠 Стек технологий
- **Разметка:** HTML5 (семантическая верстка)
- **Стилизация:** CSS3 (адаптивность, flexbox)
- **Скрипты:** JavaScript (ES6+, работа с DOM, события, Fetch API, модули)
- **Инструменты:** Git, ESLint

## ⚙️ Как запустить проект локально
Так как проект использует чистый JavaScript, для его запуска не требуется установка зависимостей. Достаточно открыть файл `index.html` в браузере.

Если вы хотите запустить локальный сервер (например, для корректной работы с модулями), можно использовать любой удобный инструмент, например:
